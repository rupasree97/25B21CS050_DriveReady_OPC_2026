# Day 2 – Sweet Crumbs Home Bakery Chatbot

## Objective
Build a simple business chatbot using Python and an LLM.

## Business Problem
Sweet Crumbs Home Bakery needs a chatbot to answer customer questions about its menu, prices, eggless cakes, and order requirements.

## Concepts Learned
- System prompts
- Role, Facts, Rules, and Format
- Few-shot prompting
- JSON and Python dictionaries
- Python functions and decorators
- Conversation history and memory limits
- Error handling
- API calls using Groq

## Technologies Used
- Python
- Google Colab
- Groq API
- OpenAI Python library

## Features
- Answers bakery-related customer questions.
- Provides menu prices.
- Answers questions about eggless cakes.
- Remembers conversation details during the chat.
- Handles API errors.
- Uses a Python function to calculate item prices.

## Files
- `Day2_Sweet_Crumbs_Chatbot.ipynb` – Chatbot implementation.

## How to Run
1. Open the notebook in Google Colab.
2. Add `GROQ_API_KEY` to Colab Secrets.
3. Enable access to the secret.
4. Run the notebook cells.

## Learning Outcome
Learned how to create a business-specific chatbot using system prompts, Python functions, conversation history, and error handling.
