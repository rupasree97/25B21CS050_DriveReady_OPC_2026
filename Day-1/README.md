# Day 1 – First LLM API Call

## Objective
Learn how to connect a Python program to a Large Language Model (LLM) using an API.

## Concepts Learned
- What is an LLM?
- What is an API?
- Connecting to Groq using an OpenAI-compatible client.
- Understanding system and user messages.
- Sending prompts and receiving model responses.

## Technologies Used
- Python
- Google Colab
- Groq API
- OpenAI Python library

## Implementation
Created a simple Python program that sends a user prompt to an LLM and prints the generated response.

## Files
- `Day1_First_LLM_API_Call.ipynb` – Day 1 implementation.

## How to Run
1. Open the notebook in Google Colab.
2. Add your Groq API key to Colab Secrets with the name `GROQ_API_KEY`.
3. Enable notebook access to the secret.
4. Run the notebook cells.

## Learning Outcome
Learned how to make my first LLM API call using Python.
